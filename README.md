# 🎵 Spotify Clone

A modern full-stack Spotify-inspired music streaming application built with **React**, **Node.js**, **Express**, and **PostgreSQL**. Users can browse songs, create playlists, manage their queue, view lyrics, and enjoy a smooth music playback experience through a clean and responsive interface.

---

## 🚀 Features

### 🎧 Music Player
- Play, pause, next, and previous controls
- Volume and mute controls
- Progress bar with seeking
- Shuffle and repeat modes
- Queue management
- Drag & drop queue reordering
- Lyrics / Waveform toggle

### 👤 User Authentication
- User registration
- Secure login
- JWT authentication
- Protected routes

### 👥 User Profile
- User profile page
- Recently played songs
- Favorite songs
- User playlists
- Account overview

### 📂 Playlist Management
- Create playlists
- Add songs to playlists
- Remove songs
- Playlist browsing

### ❤️ Song Library
- Browse all songs
- Search songs
- Like/Favorite songs
- Song context menu

### 🛠 Admin Dashboard
- Add songs
- Edit songs
- Delete songs
- Manage music library

### ⚡ User Experience
- Responsive design
- Toast notifications
- Keyboard shortcuts
- Modern Spotify-inspired UI
- Smooth navigation

---

### Frontend
- React

### Backend
- Node.js

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/khushnoodahmad890-cloud/spotify-clone-react.git
```

### Install Frontend

```bash
cd client
npm install
```

### Install Backend

```bash
cd ../server
npm install
```

---

## ▶️ Running the Project

### Start Backend

```bash
cd server
npm run dev
```

### Start Frontend

```bash
cd client
npm run dev
```

---

## 🗄 Database Setup

1. Create a PostgreSQL database.
2. Import:

```
spotify_clone.sql
```

3. Configure your environment variables.

Example:

```env
DB_HOST=
DB_PORT=
DB_NAME=
DB_USER=
DB_PASSWORD=

JWT_SECRET=
```
